# 0.11.0

The interface speaks English, transcription follows the language spoken, and a global shortcut starts a recording from anywhere.

- The interface is available in French and English. It follows the macOS language order: English when English comes before French, French otherwise. A per-app language set in System Settings › General › Language & Region also works. Demo content, stored default voice labels ("Voix 1", "Voix à nommer"), exports and summaries stay in French. See [localization](../localization.md).
- Transcription is no longer French only. Each track (microphone and system) gets its own language, detected from its first 90 seconds among the Apple Speech languages installed for HWYD. When detection is not conclusive, HWYD uses the first preferred system language that is installed, otherwise French.
- The setup screen can force one language for a session. A transcribed session can be reprocessed with automatic detection or in another installed language (**Transcribe Again**).
- When a track seems to be in a language that is not installed, a notification offers **Install and reprocess** or **Choose the language**. Speech that no installed model can handle is reported as not recognized.
- Settings › Audio & Voice lists the installed languages and installs others (**Add a language**). Only Apple SpeechTranscriber is used; each language is about 350 MB, downloaded once. Audio is not sent anywhere for transcription. The former default language setting is gone.
- The transcript header shows the language, per track when they differ.
- New global shortcut to start or end a recording, default ⌃⌥⌘R. It works while another application is in front, uses the last session type and automatic language detection, and leaves the window where it is. Change or remove it in Settings › General. It needs no Accessibility permission; HWYD warns when another application already uses the combination.
- `hwyd-pipeline languages` prints the installed and supported speech locales as JSON.

## Upgrade notes

- Sessions recorded before 0.11.0 have no stored language and stay French. Reprocess one to detect its language or to choose another.
- French is the only language installed by earlier versions. Add other languages in Settings › Audio & Voice; Apple Speech reserves models per application, so a language installed on the Mac for another app may still need an install for HWYD.
- If this release is the first one signed with a Developer ID certificate and notarized by Apple, macOS treats it as a new signer: microphone, system audio and calendar access may need to be granted again, and the keychain may ask once more for access to stored API keys and voice prints.

## Known limits

- Detection reads only the start of each track. A language change later in the session is not followed.
- Code-switching inside a track or a sentence is not handled: a track is transcribed in one language.
- Portuguese may be suggested as Spanish (the message names both).
- Korean speech produces no text with French or English models and is treated like silence.
- Summaries are still written in French, whatever the transcript language.
- The global shortcut has not yet been exercised from another application during a real session.
