# 0.6.0

A quieter Studio interface. The layout, the palette and every feature stay; the screens say less and stay consistent.

- Start a session under one name and one icon everywhere: "Nouvelle session" in the sidebar, the library and the menu bar. The sidebar entry becomes the running session during a capture, which no longer appears twice.
- Give each icon a single meaning: voice memos and free sessions no longer reuse the app logo and the recording symbol.
- Halve the height of the player: thinner tracks, no title, no separate position slider. With the player focused, the left and right arrows move playback by 5 seconds, and the position is adjustable by assistive technologies.
- Show the voice tiles on every tab of a session, with their instructions behind a help button.
- Replace "Corriger ce passage" on every transcript line with a single menu button at the end of the line.
- Remove the tagline, the local-storage card and the footnotes from the library, the capture screen and the transcript. Explanations that matter moved to tooltips and help buttons.
- Announce the discovery mode once per screen instead of four times on the capture screen.
- Rework the integrated settings: one setting per line, changes apply immediately, no save buttons. Models show whether they are installed. Remembered people are managed under "Audio et voix". "Données locales" and "Agents et exports" are merged.
- Hide the audio retention preference, which never deleted anything. The stored value is kept.
- Use four text sizes across the interface.
- Rename the example voice "Speaker 3" to "Voix 3", as the pipeline names voices.

The "installed" state of a model is inferred from an installation done in this version or from an existing transcript; a model installed earlier and never used shows "Installer" until then. Audio retention is still not enforced. Other limitations from the README are unchanged.
