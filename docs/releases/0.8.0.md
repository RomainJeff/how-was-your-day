# 0.8.0

Summaries can now be written by your own coding agent, with the context it already has about you.

- New summary provider: **Agent (ACP)**. HWYD starts an agent that speaks the Agent Client Protocol (Claude Code through `claude-agent-acp`, Codex through `codex-acp`, Mistral Vibe through `vibe-acp`, Grok through `grok agent stdio`, Gemini CLI through `gemini --experimental-acp`, or any other ACP command), in the working directory you choose.
- The agent receives the session title, transcript passages and voice names, and is asked to consult its own context read-only (instructions, memory, notes) to place people and projects. What it brings from that context goes into a separate **Contexte** section with its sources; the rest of the summary reports only what was said.
- The agent hands the summary back through a single MCP tool, `submit_summary`, served by `hwyd-mcp` for that session only. Submissions get the same checks as other providers; a rejected submission returns the reason so the agent can correct it. An agent that answers with the summary as text instead is validated the same way.
- HWYD answers the agent's permission requests: reading and searching are allowed, editing, deleting, moving, running commands and switching modes are refused. Permissions already granted in the agent's own configuration do not go through HWYD.
- Hosted providers: after saving an API key, the settings list the provider's models, as a menu and as completions. The key is checked first; a rejected key is not stored. The separate "send transcripts" switch is gone: choosing a hosted provider and saving its key is the opt-in.
- Meeting reminders and the upcoming meetings list offer both "Rejoindre et enregistrer" (opens the video link and records) and "Enregistrer" without joining, for meetings that have a video link.
- Hosted providers retry a stage once when the model's output fails validation, and errors now name the rule that failed.

Agent summaries depend on the agent being installed and signed in. They take about one to three minutes and use your agent subscription. Other limitations from the README are unchanged.
