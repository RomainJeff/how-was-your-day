# 0.7.0

Summaries can now run on a hosted model, in addition to a local server.

- Choose the summary provider in the settings: local server (LM Studio, Ollama), Mistral, OpenAI, Anthropic or Google Gemini.
- Hosted providers use your own API key, stored in the macOS keychain on this Mac only. Keys never appear in preferences, exports, the database or summary provenance.
- Nothing is sent until you enable "Envoyer les transcripts à …" for that provider. Each summary then sends the session title, transcript passages and voice names. Notes, audio and voice fingerprints are never sent.
- Hosted models read much larger portions per request: up to 200,000 characters instead of 24,000, so a typical one-hour session is summarized in two requests. Local servers keep the previous bounded budget.
- Provider errors (rejected key, quota, unsupported schema) are shown with the provider's own message.

Hosted requests reuse the local prompts and schema; array size limits are applied to the response because hosted engines do not all accept them. Structured-output support varies by model, and these providers have been checked against their request formats, not benchmarked for summary quality. Costs are billed to your provider account. Other limitations from the README are unchanged.
